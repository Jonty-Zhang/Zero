# 在网页里接通 Boss 可用的模型

## 目标和现状

用户希望选文件夹、给 Boss 任务，由负责人组织其他 Agent 完成。现有运行时已有跨 Agent 咨询、按阶段重规划和负责人模型验收，但连接页面只显示状态，未验证模型会禁用项目提交。用户仍须在终端登记或验证模型，再重启 Zero。这是本轮优先处理的入口障碍。

本轮实现网页 Codex 模型连接验证和安全运行时刷新。它不表示接管 Codex 桌面聊天；CLI 仍是当前后台执行通道。其他 Agent 和持续 Boss 对话不冒称随本轮完成。

## 用户流程

打开管理连接后，页面读取可选模型和运行入口状态。用户可选择已登记模型或输入准确的模型标识，选择思考强度，再明确点击验证按钮。按钮说明会发起一次真实模型调用并使用额度；查看页面、刷新或恢复轮询不会调用模型。

验证以持久化作业进行。页面展示运行、成功或失败，关闭再打开仍可查询原作业。网络超时后首先查询或重取同一请求，不把不确定结果变成新的调用。失败后的再次验证须由用户显式发起。

成功验证须让后续 Boss 任务实际获得可用候选，无须用户重启；不能只更新页面标记。已经运行的尝试继续使用原适配器，取消操作必须找到对应原进程，新绑定不能改变在途任务。

热生效是本次网页真实验证成功后的明确操作，不能将每次从配置读取的新指纹自动授权。外部配置替换、绑定撤销及其他 Agent 的启动绑定守卫仍须保留。新增 Codex 适配器也要重新核对最新配置，拒绝已经失效的身份、版本或思考强度证明。

## 约定接口

- `GET /api/connections/setup`：Codex 入口状态、已登记模型和思考强度。
- `POST /api/connections/codex/verify`：模型、思考强度和幂等请求标识；接收后返回持久化作业。
- `GET /api/connections/verifications/:id`：只读查询作业。

复用现有真实验证、模型身份和精确思考强度证明，失败不能生成可用绑定。新模型登记与绑定验证分开，禁止模糊匹配或冲突覆盖。模型输入须按参数值处理，不能成为命令或选项。

幂等键绑定准确载荷，同模型和强度的在途验证须去重。服务重启或多个服务共享数据目录时，不能仅因当前实例编号变化就宣布旧调用已结束；未确认的作业不自动重新调用模型。

## 验证要求

先保留失败测试，再实现。真实 HTTP、SQLite 和运行时适配器夹具覆盖首次无绑定、模型登记、验证成功后可派发、失败不就绪、重复请求、断线与重开、实例变化、配置撤销，以及在途任务取消仍落到原适配器。

真实 App 测试覆盖按钮、状态反馈和 Boss 提交能力更新。验证中使用替代模型适配器，不调用真实模型或读取个人账户配置。关键绑定刷新和调用去重需独立复核后提交推送。

## 实现与验证记录

网页、持久化验证服务和生产运行时已接通。验证作业另存于 `connections.sqlite`，请求键与原始载荷绑定；别名和本地模型 ID 的在途请求合并后，响应包含该作业实际接收过的 `requestedModelIds`。前端只按这个服务端关联接受别名结果，不放宽模型与强度校验。

`markVerified` 在写锁内返回本次绑定和完整证明的快照。热激活在最后一次配置读取后同步核对该快照，再授权候选；后续探测和执行继续核对同一证明。验证后替换模型身份、撤销证明或删掉强度证据均不能继续使用新连接。启动时已有绑定保持原有兼容规则，本轮未重写历史绑定迁移。

模型调用与结果落库分开。写入启动状态失败时不调用模型；结果落库失败时保留原作业归属，查询只补写结果，不重复调用。活进程持有的验证不能被另一个服务实例宣布中断；死进程的未确认作业不自动续跑。

独立复核曾复现一处激活竞态：事后校验证明虽抛错，却已留下可用候选。修复把完整证明检查移到授权提交前，并增加持续撤销检查。相同受控竞态下，候选为空，执行被拒绝，假模型调用数为零。关键复核使用 GPT-6 Astra high，重新编译和相关 25 项测试通过。

明确拒绝与未知结果分开处理。只有验证服务在准入前抛出的 400/409 会带 `verificationNotStarted: true`；前端收到该标记才允许修改原输入。网络错误、无标记的冲突和 5xx 都保留原请求。冲突键对应的旧作业仍保留，换输入后的验证须用户再次点击发起。

验证全部使用假模型适配器和隔离仓库，没有发起真实模型调用或读取个人认证配置。真实 HTTP、SQLite、Boss、Worker、检查器、Reviewer、Git 提交和报告的串联测试已到达 `done`，服务未重启；另有错误实际模型、别名并发去重和验证后配置替换的对照。最终生产核心构建成功，根代理运行 149 项配置、身份、运行时守卫、取消、生产启动、HTTP 接口及连接流程回归，全部通过。记录位于本地忽略目录 `data/verification/boss-workflow-round21/root-final-regression.log`。

前端最终 273 项交互测试、18 项 API 测试和生产构建通过，包含明确拒绝后修改模型、未知响应保留原键、关闭重开后查询恢复及 Boss 提交解禁。本地服务已加载本轮构建，网页返回 200，健康与新连接选项接口正常，队列为空。读取选项没有发起模型验证；真实账户授权和模型可用性仍须用户明确点击验证后才能确认。
